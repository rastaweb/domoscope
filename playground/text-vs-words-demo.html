📊 Text vs Words Statistics Demo

🤔 What's the Difference?

Total Added Texts: Counts how many text nodes (DOM elements containing text) were added.

Total Added Words: Counts how many individual words were added across all text nodes.

Example: Adding one paragraph "Hello beautiful world" = 1 text + 3 words
